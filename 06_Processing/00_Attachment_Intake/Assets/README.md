# Assets Intake

Thư mục này lưu các asset note được phát hiện trong lúc thu thập tài liệu, ví dụ biểu mẫu, link tải, file DOCX/PDF liên quan.

Dùng template:

```text
03_Templates/Template_Asset_Intake.md
```

Trong tracking note chính, chỉ link tới asset:

```yaml
related_assets:
  - "[[asset-ten-bieu-mau]]"
```

Quy định field và enum chuẩn xem tại:

```text
03_Templates/Template_Metadata_Field_Guide.md
```
